# Room acoustics analyzer
An interactive web-based tool designed to analyze room acoustics and help users determine optimal speaker placement for improved sound quality.

1. Overview
An application that tells you which is the best spot to place your speaker in a room. It uses Sabine Equation a mathematical formula used to calculate reverberation time (RT60) in a room, based on its volume, boundary surface area, and average absorption coefficient.

2. Features
- Interactive room layout visualization
- Speaker placement analysis
- Room dimension inputs
- Acoustic visualization and analysis
- User-friendly interface and explanation

3. Languages used
- HTML
- JavaScript
- CSS
